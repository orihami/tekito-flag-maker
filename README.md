# 適当国旗メーカー

国旗のデザインをパターンに削減して、ランダムに「なんかありそうな国旗」を作るアプリです。

**遊ぶ: https://orihami.github.io/tekito-flag-maker/**

## 仕組み

国旗はだいたい部品の組み合わせでできている、という発想で作っています。

- **レイアウト（15種）**: 横条・縦条・北欧十字・カントン・斜め十字・斜め帯・ホイスト三角・縁取り・四分割・円・シェブロン・Y字・中央十字・放射・単色＋帯
- **色（約40組）**: 実在の国旗でよくある色の組み合わせから選択し、隣り合う色やマークの色はコントラストが付くように調整
- **マーク（8種＋なし）**: 星（1〜7個、並び方もランダム）・円・三日月＋星・菱形・太陽・輪・三角・小十字。置く位置はレイアウト側の「置き場」（カントン内、円の中、三角の中など）に従う
- 架空の国名と「国旗っぽさ％」も適当に付けます

## 機能

- シード付き乱数で再現可能。URLの `#` 以降がシードで、リンクを共有すると同じ旗が出ます
- レイアウト／色／マークを固定して部分だけ再抽選
- 複雑さ（シンプル／ふつう／ごちゃめ）と縦横比の切り替え
- PNG / SVG で保存、作った旗の履歴（クリックで再表示）
- Space キーでも新しい旗が作れます

単一の `index.html` だけで動きます（外部依存なし）。
